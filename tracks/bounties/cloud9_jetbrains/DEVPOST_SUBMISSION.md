# C9 Fearless Command

**Category 2 · League of Legends — Macro Scouting & Draft Management System**

Scout an opponent, play out a Hard Fearless series, and see which earlier games support the next pick.

## Inspiration

A scouting sheet can tell a coach what an opponent likes to play. The harder question comes after Game 1: if neither team can pick those champions again, which alternatives has the opponent actually shown? We wanted a coach to be able to ask that question without switching between a draft board, an objective report and a spreadsheet.

## What it does

Start with the opponent. Filter by patch and map side; compare opening bans, most-played champions, first objectives by 15:00 and gold difference at 15. Each figure has a count. A thin slice of games should look like a thin slice, not a confident trend.

Then play a hypothetical best-of-five. Choose a ban or pick, compare legal alternatives, and watch blue's estimated win probability change. Candidate deltas are in percentage points for the **acting side**; the chart tracks **blue versus its pre-draft estimate**. Record a scenario winner to advance. Both teams' picks become series locks; bans expire. The coach brief names a replacement only when there are observations to support it, and tells you how many *pick turns* and *distinct games* they came from.

## How we built it

Our Python reader streams licensed LoL event feeds outside the repository. It checks session validity, orders draft actions and reconciles reversed objective events. A shared rules engine drives historical reconstruction and the interactive board. A regularized logistic model adds draft features to pre-draft Elo; its stage weight can be zero when earlier validation does not support a change. The browser uses plain HTML, CSS and JavaScript. Advice is assembled from counted evidence, not generated by a language model. [Engineering workflow and tool disclosure](AI_SHOWCASE.md)

## Challenges we ran into

“Earlier in the file” is not the same as “known at draft time.” Results from an unfinished series must not update team strength. A previous game's picks may impose locks, but only if that game had finished and its board can be verified. We treat those as separate clocks. We also keep unknown historical formats unknown instead of inferring Hard Fearless from a lack of repeat picks.

## Accomplishments that we're proud of

The licensed cache covers **728 valid series, 1,697 games and 1,695 complete ordered drafts**. Training used 582 series / 1,318 drafts. The holdout began at `2026-02-02T15:46:17.180000+00:00` and contained 146 series / 377 drafts. To isolate what the draft adds, compare the same games before the first action and after the last. Brackets show 95% percentile intervals from 2,000 whole-series bootstrap resamples.

| Held-out model | AUC [95% CI] | LogLoss [95% CI] | Brier [95% CI] |
| --- | --- | --- | --- |
| Pre-draft Elo | 0.6166 [0.5527, 0.6796] | 0.6714 [0.6484, 0.6945] | 0.2392 [0.2281, 0.2501] |
| Draft after 20 steps | 0.6168 [0.5526, 0.6797] | 0.6701 [0.6456, 0.6944] | 0.2386 [0.2269, 0.2501] |

The more practical result: a judge can run the same board without a data license. All 25 tests passed locally, including a browser test that finishes Game 1, advances to Game 2 and checks that ten picks are locked. The full suite and the independent source-data refit both exited 0 on 2026-11-24.

## What we learned

Most of the measured predictive signal was already present before the draft. At six actions the fitted draft model returned exactly the Elo baseline. The full draft's point estimates were slightly better, but these intervals describe individual models, not their paired difference. We do not claim statistical significance, causal pick effects, or better match outcomes for coaches. Showing *why a replacement is plausible* is useful even when the probability barely moves.

## What's next for C9 Fearless Command

Test the workflow with coaches: does showing distinct games alongside pick turns change which alternatives they prepare? On the modeling side, check the incremental draft signal on another chronological holdout and estimate a paired interval for the change versus Elo before making a stronger claim.

## Public Demo vs Licensed Local Mode

- **Public practice:** From the repository root run `python -B tracks/bounties/cloud9_jetbrains/app/server.py --demo` and open `http://127.0.0.1:8000/`. Teams, champions and match histories are generated; coefficients are illustrative. A localhost address is not a hosted judging link.
- **Licensed local:** Eligible participants supply their own authorized starter checkout via `STL_DATA_DIR` and a separate external `C9_CACHE_DIR`. The workbench reads the local cache; `--revalidate` and `--as-of` rescan the licensed source. The evaluation above is from the licensed run, not the synthetic demo.
